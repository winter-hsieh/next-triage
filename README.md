# 下一位：Triage

**Emergency Department Triage Simulator** — 急診檢傷模擬遊戲

▶ 線上遊玩：https://winter-hsieh.github.io/next-triage/

你是急診的檢傷護理師。病人一個個進來，你要問診、判斷 TTAS 級數；問得越仔細越準，但外面排隊的人正在惡化。

- 不需安裝、不需帳號，電腦或手機開網頁就能玩（電腦體驗較佳）。
- 預設為離線模式：病人依關鍵字回答。
- 想讓 AI 即時扮演病人，可以在遊戲的「AI 設定」填入**自己的** API key（Gemini 有免費額度）。key 只存在你自己的瀏覽器，遊戲直接連到 Google 或 Anthropic。

分級依據衛福部急診五級檢傷分類基準簡化。案例與人物皆為虛構，如有雷同，純屬巧合。
